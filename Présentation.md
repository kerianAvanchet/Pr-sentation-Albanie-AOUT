## Thème 1 : fichiers

* **HTML** : langage qui donne la structure d'une page web (titres, paragraphes, liens, images).

* **CSS** : langage qui donne le style d'une page (couleurs, tailles, bordures, placement).

* **JavaScript** : langage qui rend une page interactive (boutons, formulaires, animations).

---

## Thème 2 : markdown

* `#` : crée un titre. Plus il y a de `#`, plus le titre est petit.

* `*` : crée une liste à puces.

* `**` : met un mot en **gras**.

* `<!-- -->` : commentaire, invisible dans le rendu.

---

## Thème 3 : outils

* **Visual Studio Code** : éditeur de code gratuit. Avec l'extension Marp, il affiche les slides.

* **DBeaver** : logiciel pour se connecter à une base de données et lire ou modifier ses tables.
